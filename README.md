# Departamentos Luz — MVP

MVP de vitrina digital para arriendos en San Bernardo.

## Experiencia
- Disponibilidad visible por unidad.
- Fichas con fotografías y características.
- Consulta directa por WhatsApp con contexto.
- Solicitud de visita con fecha y horario preferidos.
- FAQ para reducir preguntas repetidas.
- Diseño responsive y CTA móvil persistente.

## Sistema visual
- **Display:** DM Serif Display.
- **UI / lectura:** Manrope.
- Tokens semánticos para color, superficie, estados, acciones, espaciado, radios y motion.
- Microinteracciones y soporte `prefers-reduced-motion`.
